Comprendre les coffres leurres et leurs PIN

Les versions récentes de Hide Photos permettent jusqu'à trois coffres leurres possédant chacun un PIN, du contenu et une clé propres. Les réglages s'effectuent depuis le coffre principal.

Ce n'est pas une protection garantie contre la coercition. Face ID et la récupération de PIN peuvent être indisponibles lorsqu'un leurre est activé. Chaque coffre est sauvegardé séparément.

Points à vérifier

PIN et clés

Le PIN n'est pas enregistré en clair. Argon2id dérive une clé KEK qui protège une clé maîtresse aléatoire de 256 bits. Face ID ne sert qu'au déverrouillage local pratique.

Protections d'iOS

Les fichiers sont stockés dans l'espace Application Support privé, avec Complete File Protection. Un écran de confidentialité masque l'aperçu en arrière-plan ; les fichiers temporaires déchiffrés sont nettoyés.

Sauvegarde chiffrée indépendante

Vous choisissez Files, iCloud Drive, un disque externe ou un autre fournisseur. La sauvegarde utilise un sel aléatoire distinct et une enveloppe de clé protégée par PIN. La restauration demande fichier et PIN, pas le Face ID de l'ancien appareil.

Centre d'assistance

Le développeur peut-il retrouver mon PIN oublié ?

Non. Aucune copie serveur des identifiants du coffre n'existe ; le développeur ne peut pas déverrouiller le coffre à distance. Utilisez uniquement les méthodes de récupération déjà configurées et disponibles dans votre version.

Pourquoi faut-il un PIN pour restaurer une sauvegarde ?

Le fichier seul ne doit pas permettre le déchiffrement. Conservez le bon PIN en lieu sûr et testez la restauration.

Comment changer d'iPhone ?

Créez une sauvegarde chiffrée sur l'ancien appareil, conservez le fichier et le PIN, puis restaurez sur le nouveau. Face ID doit être reconfiguré sur le nouvel appareil.
