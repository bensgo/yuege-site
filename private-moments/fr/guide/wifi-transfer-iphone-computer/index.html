Transfert Wi-Fi vers Windows et Mac

  1. Ouvrez Hide Photos sur l’iPhone et sélectionnez les albums et dossiers à partager.
  2. Démarrez Wi-Fi Transfer et copiez l’adresse affichée. Gardez l’application ouverte.
  3. Ouvrez cette adresse dans un navigateur Windows ou Mac sur le même réseau local.
  4. Autorisez l’ordinateur sur l’iPhone, transférez vos fichiers, puis arrêtez le service.

FAQ

Compatible avec Windows ?

Oui. Utilisez Chrome ou Edge sous Windows.

Les transferts sont-ils chiffrés ?

Non. HTTP ne chiffre pas les données en transit.

Est-ce réservé à Pro ?

Oui. Wi-Fi Transfer nécessite Pro.
