端末上の保護

「隠す」だけではなく、暗号化。

Vaultメディアを暗号化

写真・動画などのVaultコンテンツは、認証付き暗号AES-GCMを使って端末上で保護します。

Face ID + パスコード

6桁PINと任意のFace IDでVaultへのアクセスを保護します。

iOSのファイル保護

暗号化されたメディアや関連データには、iOSの保護機構も組み合わせます。

プライベートな保存領域

Vaultデータはアプリ専用の保存領域で管理されます。

サーバー保存について

写真・動画そのものを当社サーバーに保管しません。

Photo Vaultに保存した写真・動画そのものを、当社が運営するサーバーへアップロードして保管する仕組みはありません。ユーザーが明示的に共有・書き出し・バックアップを行った場合は、選択した外部サービス側のポリシーが適用されます。

利用状況の分析

Firebase Analyticsは、Vaultの中身を見るためのものではありません。

アプリ品質の改善と、どの機能が利用されているかを把握するため、Firebase Analyticsを利用します。

✓Vault内の写真・動画そのものを分析イベントとして送信しません
✓写真・動画の内容、Moment本文、PIN、暗号鍵を送信しません
✓IDFAを使用しません
✓AdSupportを導入しません
✓IDFV収集を無効化します
✓広告を配信しません
✓Google Signals・広告関連機能を有効にしません

Firebaseが処理する技術情報については、GoogleのFirebaseおよびプライバシーに関する説明もご確認ください。

絶対的な安全を保証するものではありません。 どのソフトウェアにもリスクはあります。Photo Vaultは、プライベートデータの露出を減らし、確立された暗号技術とiOSの保護機構を組み合わせることを重視しています。最終更新: 2026年10月5日。
