Hide Photos: Secret Album

暗号化と安全性の仕組み

AES-GCM、PINと鍵の保護、iOSのファイル保護、暗号化バックアップ、分析データの範囲をご説明します。

隠すだけでなく暗号化

写真、動画、サムネイル、Moment本文やメタデータは認証付きAES-GCMで保護。大きなメディアは分割して暗号化します。

PINと鍵の保護

PINは平文保存しません。Argon2idで導出したKEKがランダムな256ビットのマスター鍵を保護します。Face IDは端末上のロック解除のための補助です。

iOSによる追加保護

ファイルはApplication Supportの非公開領域に保存し、Complete File Protectionを利用します。背景移行時にプレビューを隠し、復号した一時データを適切に消去します。

プライベートカメラとメタデータ

アプリ内で撮影したメディアは保管庫に直接入ります。サムネイル、タイトル、メモも機密データとして扱います。

暗号化バックアップ

保存先はFiles、iCloud Drive、外部ストレージなどから利用者が選びます。独立したランダムソルトとPINで保護される鍵情報を使用し、復元にはファイルと正しいPINが必要です。

分析と限界

Firebase Analyticsは限定的な利用・品質分析のみで、取り込み操作、保存件数、保管庫の中身は送信しません。IDFA、AdSupport、IDFV収集、Google Signalsと広告機能は使用しません。絶対的な安全性は保証できません。
