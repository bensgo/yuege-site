デコイPIN付き写真保管庫の仕組み

新しいHide Photosでは最大3つのデコイ保管庫に個別のPIN、内容と鍵を持たせられます。管理はメイン保管庫内で行います。

強制的な開示に対する安全を保証する機能ではありません。利用中はFace ID解除とPIN復旧が使用できない場合があり、各保管庫のバックアップは別々です。

確認するポイント

PINと鍵の保護

PINは平文保存しません。Argon2idで導出したKEKがランダムな256ビットのマスター鍵を保護します。Face IDは端末上のロック解除のための補助です。

iOSによる追加保護

ファイルはApplication Supportの非公開領域に保存し、Complete File Protectionを利用します。背景移行時にプレビューを隠し、復号した一時データを適切に消去します。

暗号化バックアップ

保存先はFiles、iCloud Drive、外部ストレージなどから利用者が選びます。独立したランダムソルトとPINで保護される鍵情報を使用し、復元にはファイルと正しいPINが必要です。

サポートセンター

PINを忘れた場合、開発者が復元できますか？

できません。開発者にはサーバー上の復元用認証情報がなく、遠隔でPINや暗号化された保管庫を復元できません。設定済みの対応する認証・回復方法をご確認ください。

バックアップの復元にPINが必要なのはなぜ？

バックアップファイルだけでは復号できないよう保護しているためです。正しいPINを安全に保管し、復元をテストしてください。

新しいiPhoneに移すには？

旧端末で暗号化バックアップを作り、ファイルとPINを保管してから、新しい端末で復元します。Face IDは新端末で設定し直します。
