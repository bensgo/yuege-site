クラウドに保存しないiPhone写真保管庫

秘密の写真を開発者のクラウドへ自動送信せず、iPhone内で管理したい人向けに、端末内保存の仕組みと失わないためのバックアップ方法を解説します。

結論：保存場所とバックアップは別々に考える

Hide Photosの現在公開中のバージョンでは、取り込んだ写真・動画・MomentをiPhone内のアプリ専用領域に暗号化して保存します。利用にアカウント登録は必要なく、保管庫の内容を開発者が運営する写真クラウドへ自動アップロードしません。

ただし、端末内だけに保存することと、データを失わないことは別です。iPhoneの故障、紛失、初期化、Appの削除に備えるには、利用者自身で暗号化バックアップを作成する必要があります。

Apple写真・iCloud写真との違い

Apple写真でiCloud写真をオンにすると、写真や動画はiCloudへアップロードされ、同じApple Accountのデバイス間で変更が同期されます。Hide Photosの端末内保管庫は、その写真ライブラリとは別の保存領域です。

Hide Photosを使うためにiCloud写真をオフにする必要はありません。Apple写真から項目を取り込む際、原本がiCloudにだけある場合は、iPhoneへダウンロードできる通信環境が必要になることがあります。

端末内ではどのように保護される？

アプリ専用領域に保存

取り込んだ写真、動画、サムネイル、Moment、関連メタデータは、通常のApple写真ライブラリとは別のアプリ専用領域で管理されます。

AES-GCMで暗号化

保管庫のメディアは認証付きAES-GCMで暗号化されます。大きなファイルは分割して処理され、PINと端末上の鍵管理で保護されます。

PINとFace ID

保管庫は独立した6桁PINでロックし、任意でFace IDを利用できます。開発者はPINや保管庫の復号情報をサーバーから照会できません。

暗号化はリスクを減らすための仕組みですが、絶対的な安全性や、端末自体が侵害された場合の保護を保証するものではありません。

取り込んだ後、Apple写真の元画像はどうなる？

写真を取り込んだだけで、Apple写真の元画像が自動的に削除されることはありません。取り込み完了後に元画像を削除するかどうかを利用者が選びます。

  1. Hide Photosで取り込み結果を開き、写真や動画が正常に表示できることを確認します。
  2. 必要に応じてアルバムやMomentへ整理します。
  3. Apple写真側の元画像を削除する場合だけ、確認画面から操作します。
  4. iCloud写真を利用中なら、削除がほかの同期端末にも反映されることを確認します。

Appleによると、iCloud写真を使用している場合、1台の端末で削除した写真や動画は同じApple Accountのほかの端末からも削除されます。citeturn5search1

クラウド自動同期なしでデータを失わないために

現在の端末内保管庫は自動クラウド同期ではありません。大切な項目を保存したら、定期的に暗号化バックアップを作成してください。

  1. Hide Photosのバックアップ機能から暗号化バックアップファイルを作成します。
  2. Files、外部ストレージ、または利用者が選んだ保存先へ保管します。
  3. バックアップファイルと対応するPINを、同時に失わない方法で管理します。
  4. 機種変更前に新しいiPhoneで復元し、写真・動画・Momentを確認します。
  5. 復元確認が終わるまで、古いiPhoneや元のバックアップを消去しません。

バックアップファイルをiCloud Driveへ置く場合、そのファイルは利用者自身のiCloudに保存されます。これはHide Photosが保管庫を開発者サーバーへ自動同期することとは異なります。

Appを削除する前の注意

暗号化バックアップを作成せずにAppを削除したりiPhoneを初期化したりすると、端末内の保管庫を復元できない可能性があります。削除前にバックアップファイル、PIN、復元結果の3点を確認してください。

Face IDは便利なロック解除手段ですが、バックアップ復元に必要なPINの代わりにはなりません。PINを忘れた場合、開発者が遠隔で復元することもできません。

端末内写真保管庫が向いている人

  • 秘密の写真を開発者のクラウドへ自動送信したくない人
  • アカウント登録なしで写真保管庫を使いたい人
  • Apple写真と別のPINでプライベートな項目を管理したい人
  • バックアップの保存先とタイミングを自分で決めたい人

複数端末への自動同期を最優先する場合は、端末内保存だけでなく、利用するサービスの同期方式、暗号化、復元方法も比較してください。
