Encryption

Real encryption, not just hidden files.

Sensitive vault content is protected with authenticated AES-GCM encryption rather than being stored as ordinary readable media.

◈

Vault content is encrypted

Photos, videos, thumbnails, Moment titles, notes and vault metadata are protected.

⌁

Chunked media encryption

Large media is encrypted in bounded chunks instead of one giant plaintext object.

#

PIN protects the vault key

Your 6-digit PIN is not stored as readable text. Argon2id derives a Key Encryption Key that protects the randomly generated Vault Master Key.

◎

Face ID stays device-local

Face ID provides convenient local unlocking. Your PIN remains the portable recovery credential for encrypted backups.

Defense in depth

Encryption plus iOS protections.

▣

Complete File Protection

Encrypted media, thumbnails and metadata are additionally protected using iOS Complete File Protection.

⌂

Private app storage

Vault files live inside protected Application Support storage rather than a public Documents folder.

◐

Background privacy

Sensitive content is covered when the app leaves the foreground, with automatic locking according to your settings.

⌫

Temporary plaintext cleanup

System operations that require decrypted media use protected temporary storage that is cleaned after use, on lock, and on later startup cleanup.

◉

Private camera

Photos and videos captured inside PrivateMoment go directly into the vault rather than first being written to Apple Photos.

✦

Metadata is sensitive too

Thumbnails, Moment titles, notes and metadata are protected alongside media.

Encrypted backup

Your backup. Your storage. Your PIN.

PrivateMoment does not run a cloud backup service. You create an encrypted backup and decide where to keep it.

Portable without depending on the old device

A backup contains a portable, PIN-protected key envelope and encrypted vault data. Restoring does not require the original device's Face ID or Keychain state.

✓Save with Files, iCloud Drive, external storage or another file provider
✓Backup encryption uses an independent random salt
✓Restore on another device using the backup file and correct PIN
✓Restore is validated before replacing the current vault
Data collection

No account. No ads. No analytics tracking. No PrivateMoment server storing your vault.

We do not need to know which photos you open, which Moments you create, how often you unlock the app, or what you keep inside it.

What this architecture means

Some things are intentionally impossible for us.

✓We cannot remotely view the contents of your vault.
✓We cannot recover an encrypted backup without its correct PIN.
✓We cannot restore private content from a PrivateMoment server.
✓We cannot see the photos, videos, Moments or notes you store.

Security is a process. No software can truthfully promise that compromise is impossible. PrivateMoment focuses on reducing exposure, using established cryptographic primitives, minimizing plaintext data, and using iOS platform security where appropriate. Last updated September 26, 2026.
