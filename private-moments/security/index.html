Encryption

Real encryption, not just hidden files.

PrivateMoment does not rely on putting ordinary photos inside an app sandbox. Sensitive vault content is encrypted with authenticated AES-GCM encryption.

◈

Vault content is encrypted

Photos, videos, thumbnails, Moment titles, notes and vault metadata are protected rather than stored as ordinary readable content.

⌁

Chunked media encryption

Large media is processed in bounded chunks, avoiding the need to treat an entire photo or video as one large plaintext object.

#

PIN protects the vault key

Your 6-digit PIN is not stored as readable text. Argon2id derives a key-encryption key that protects the randomly generated Vault Master Key.

◎

Face ID stays device-local

Face ID can provide convenient local unlocking. Your PIN remains the portable credential used for encrypted backup recovery.

Device protection

Defense in depth.

PrivateMoment combines app-level encryption with iOS platform protections and minimizes where plaintext can exist.

▣

Complete File Protection

Encrypted media, thumbnails and metadata are additionally protected using iOS Complete File Protection.

⌂

Private app storage

Vault content lives inside the app's protected Application Support storage rather than a public Documents folder.

◐

Background privacy

Sensitive content is covered as soon as PrivateMoment leaves the foreground. Auto-lock can require authentication again after the configured threshold.

⌫

Temporary plaintext is short-lived

When system operations require temporary decrypted media, it stays in protected temporary storage and is cleaned after use, on lock, and on later startup cleanup.

◉

Private camera

Photos and videos captured inside PrivateMoment go directly into the private vault instead of first being written to Apple Photos.

✦

Metadata matters too

A thumbnail, title or private note can be sensitive even without the original photo. PrivateMoment protects those alongside your media.

Encrypted backup

Your backup. Your storage. Your PIN.

PrivateMoment does not run a cloud backup service. You create an encrypted backup and decide where to keep it.

Portable without depending on the old device

A PrivateMoment backup contains a portable, PIN-protected key envelope and encrypted vault data. Restoring does not require the original device's Face ID or Keychain state.

✓Save with Files, iCloud Drive, external storage or another file provider
✓Backup encryption uses its own random salt
✓Restore on another device using the backup file and correct PIN
✓Restore is staged and validated before replacing the current vault
Data collection

Nothing private needs to be measured.

No account. No ads. No analytics tracking. No PrivateMoment server storing your vault.

We do not need to know which photos you open, which Moments you create, how often you unlock the app, or what you keep inside it.

What this architecture means

Some things are intentionally impossible for us.

Keeping PrivateMoment out of your vault also means we cannot act as a recovery service for secrets we never receive.

✓We cannot remotely view the contents of your vault.
✓We cannot recover an encrypted backup without its correct PIN.
✓We cannot restore your private content from a PrivateMoment server.
✓We cannot see the photos, videos, Moments or notes you choose to store.
Security is a process. No software can truthfully promise that compromise is impossible. PrivateMoment focuses on reducing exposure, using established cryptographic primitives, minimizing plaintext data, and using iOS platform security where appropriate. This page is updated when meaningful security architecture changes are made.
