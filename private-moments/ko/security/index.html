Hide Photos: Secret Album

암호화와 보안 구조

AES-GCM 암호화, PIN과 키 보호, iOS 파일 보호, 백업 방식, 분석 범위를 설명합니다.

단순 숨김이 아닌 암호화

사진·동영상·썸네일·Moment 텍스트·메타데이터는 인증된 AES-GCM 암호화를 사용합니다. 큰 미디어 파일은 제한된 크기의 블록으로 처리합니다.

PIN과 암호화 키

PIN을 평문으로 저장하지 않습니다. Argon2id로 파생한 KEK가 무작위 256비트 마스터 키를 보호합니다. Face ID는 기기 내부의 편의 기능입니다.

iOS의 추가 보호

암호화 파일은 앱의 비공개 Application Support 영역에 저장되며 Complete File Protection을 사용합니다. 백그라운드 전환 시 내용을 가리고 임시 복호화 데이터를 정리합니다.

비공개 카메라와 메타데이터

앱 안에서 촬영한 사진과 동영상은 보관함에 바로 들어갑니다. 썸네일, 제목, 메모 역시 민감한 정보로 취급합니다.

독립적인 암호화 백업

Files, iCloud Drive, 외장 저장소 등 저장 위치를 사용자가 결정합니다. 별도의 무작위 솔트와 PIN 보호 키 정보를 사용하며 복원에는 파일과 올바른 PIN이 필요합니다. 이전 기기의 Face ID는 필요하지 않습니다.

분석 범위와 한계

Firebase Analytics는 제한된 앱 이용·품질 측정에만 사용되고 가져오기 이벤트, 미디어 건수나 콘텐츠는 전송하지 않습니다. IDFA, AdSupport, IDFV 수집, Google Signals 및 광고 기능은 사용하지 않습니다. 절대적인 안전을 보장할 수는 없습니다.
