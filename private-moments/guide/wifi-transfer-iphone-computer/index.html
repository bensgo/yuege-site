Wi-Fi Transfer for Windows & Mac

  1. Unlock Hide Photos on iPhone and select which albums or folders you want to share.
  2. Start Wi-Fi Transfer and keep the app open. Copy the address shown on your iPhone.
  3. On Windows or Mac, open that address in a browser on the same reachable local network.
  4. Approve the computer request on the iPhone, transfer files, and stop the service when done.

Wi-Fi Transfer / iCloud Sync / Backup

HTTP · Local network

Important: HTTP transfers are not encrypted

Wi-Fi Transfer uses HTTP and does not encrypt files in transit. Use a trusted private Wi-Fi network, approve only computers you recognize, and stop the service when finished.

FAQ

Does Wi-Fi Transfer work on Windows?

Yes. Use Chrome or Edge on a Windows PC connected to the same reachable local network.

Is it an encrypted transfer?

No. This version uses HTTP without transport encryption. Use a trusted private network.

Do I need iCloud or a desktop app?

No. The transfer runs locally in a browser without a separate account or developer server.

Is it a Pro feature?

Yes. Wi-Fi Transfer requires Hide Photos Pro. The app is free to download.
