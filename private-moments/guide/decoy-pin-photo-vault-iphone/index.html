Decoy Vault and Fake PIN for iPhone: Setup and Limits

A decoy vault is an alternative space that opens with a different PIN. It can be useful when you want a less-sensitive view of an app, but it is not a guarantee of safety or protection against coercion.

Written by the Hide Photos developer · Yuege Apps

What is a decoy vault?

Some private-photo apps support two destinations for different credentials: a primary vault for your private media and a decoy vault that opens using another PIN. The decoy can contain ordinary, non-sensitive items. Someone seeing that view won't necessarily see the main library, but the feature should never be treated as impossible to detect.

How Hide Photos: Secret Album approaches it

Hide Photos: Secret Album has a main private vault and an optional Decoy Vault feature. You can configure a separate decoy PIN and put content into the alternate space. Decoy Vault is a Pro feature; availability can depend on the installed app version.

Hide Photos: Secret Album also supports on-device AES-GCM encryption, a six-digit PIN and optional Face ID for ordinary access. It is designed to keep the encrypted vault content on your device without a developer-hosted photo cloud.

What a decoy PIN does not solve

A decoy PIN cannot stop someone from uninstalling your app, inspecting device backups, demanding other credentials, or noticing an app's presence. It is not a substitute for a strong iPhone passcode, keeping iOS updated, or physical safety. If you're under pressure to reveal private information, prioritize your personal safety over a software feature.

Questions worth asking before choosing an app

  • Does the alternate PIN unlock a separate library or merely show an empty screen?
  • Is the decoy space clearly isolated from your primary content?
  • What happens after repeated incorrect PIN attempts?
  • Does activating the decoy change Face ID or recovery behavior?
  • Can you make and restore an encrypted backup without mixing the two spaces?

Test with harmless sample photos first, and read the product's security explanation. Features and recovery details can change between releases.

Do you actually need a decoy vault?

If your main concern is keeping casual screenshots or personal albums separate, Apple's built-in Hidden album may be enough. If an independent access space matters to you, a decoy vault can be one consideration among several. Prefer clear documentation and tested backups over dramatic security promises.

Up to three decoy vaults, each with its own PIN and key

Hide Photos' newer version supports up to three decoy vaults, not just one. The management UI explains that each decoy has its own content, PIN and encryption key. You access vaults using the PIN on the normal unlock screen; decoy management is available only when you are in the main vault.

Important: Face ID behavior when a decoy is enabled

According to the current Decoy Vault management FAQ shown in the supplied screenshot, Face ID unlock and Face ID PIN recovery are unavailable while a decoy vault is enabled. Keep the correct PINs securely. Disabling a decoy stops its PIN from opening it but retains the vault's content and encryption keys, according to the management screen.

Frequently asked questions

How many decoy vaults can I create?

The newer version supports a maximum of three decoy vaults. The supplied management screenshot illustrates an intermediate 1/3-created state.

Can my main PIN open a decoy vault?

No. The current in-app management FAQ states that each vault has its own PIN and encryption key. Enter the particular vault's PIN on the common unlock screen.

Can I rename, disable or delete one decoy without removing the others?

The Decoy Vault Details screen provides separate Change Name, Change PIN, Enable This Vault and Delete Decoy Vault actions. Disabling retains that vault's contents and keys; deletion is a distinct destructive action.

Does Face ID work with an active decoy vault?

The supplied in-app FAQ says Face ID and Face ID PIN recovery remain unavailable while a decoy vault is enabled. Verify behavior in the version installed on your iPhone.

Can each decoy vault have a separate encrypted backup?

Yes. Open the desired vault, verify its PIN and create a backup from within it. The file covers that vault only; restoring merges into the currently unlocked destination vault after confirmation.

Does a decoy vault make the app impossible to detect?

No. It is an optional access-control feature and cannot promise invisibility or protection against coercion. Prioritize personal safety, device security and tested backup and recovery steps.

How to set up and test a fake PIN

  1. Unlock the main vault and open its Decoy Vault management screen. Check the installed version and Pro availability, then create a decoy with a PIN different from the main PIN.
  2. Lock the app and enter the decoy PIN on the normal unlock screen. Add only harmless sample content to this separate space.
  3. Lock again and enter the main PIN. Confirm that the two libraries show their own content. Repeat for another decoy only if you need it; the supported maximum is three.
  4. With a decoy enabled, plan to use PIN access: the documented management screen says Face ID unlock and Face ID PIN recovery are unavailable in this state.
  5. If you want a backup of the decoy, export while that decoy is open. Restore only into the intended destination: restoration merges missing items into the currently open vault after confirmation.
