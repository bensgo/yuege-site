Foto-Tresor mit Täuschungs-PIN

Neuere Versionen von Hide Photos bieten bis zu drei Täuschungs-Tresore mit eigenen PINs, Inhalten und Schlüsseln; verwaltet werden sie aus dem Haupttresor.

Kein Schutzversprechen bei Zwang. Während ein Täuschungs-Tresor aktiv ist, können Face ID und PIN-Wiederherstellung nicht verfügbar sein. Sicherungen erfolgen pro offenem Tresor.

Wichtige Prüfpunkte

PIN und Schlüssel

Die PIN wird nicht im Klartext gespeichert. Argon2id leitet einen Key Encryption Key (KEK) ab, der einen zufälligen 256-Bit-Tresorschlüssel schützt. Face ID erleichtert nur die lokale Entsperrung.

Zusätzlicher iOS-Schutz

Dateien liegen im geschützten Application-Support-Bereich und nutzen Complete File Protection. Im Hintergrund wird die Vorschau verdeckt; temporäre Klartextdaten werden nach Verwendung entfernt.

Verschlüsselte Sicherungsdatei

Dateien können in Files, iCloud Drive, auf externen Speichern oder bei anderen Anbietern abgelegt werden. Die Sicherung verwendet unabhängiges Zufallssalz und PIN-geschützte Schlüssel; zum Wiederherstellen braucht man Datei und PIN, nicht Face ID des alten Geräts.

Hilfe und Support

Kann der Entwickler meine vergessene PIN zurücksetzen?

Nein. Es gibt keine serverseitige Kopie der Zugangsdaten. Der Entwickler kann PIN oder verschlüsselten Tresor nicht aus der Ferne wiederherstellen. Nutzen Sie gegebenenfalls konfigurierte, in Ihrer Version unterstützte Wiederherstellungswege.

Warum braucht eine Sicherung die PIN?

Die Sicherungsdatei allein genügt absichtlich nicht zum Entschlüsseln. Bewahren Sie die richtige PIN sicher auf und testen Sie eine Wiederherstellung.

Wie wechsle ich auf ein neues iPhone?

Erstellen und speichern Sie eine verschlüsselte Sicherung auf dem alten Gerät. Stellen Sie sie auf dem neuen mit der richtigen PIN wieder her. Face ID wird gerätespezifisch neu eingerichtet.
