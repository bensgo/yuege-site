Fotos mit Passwort schützen auf dem iPhone: PIN & Face ID

Zum Sperren privater Bilder kannst du auf neueren iPhones das geschützte Album „Ausgeblendet“ verwenden. Eine andere Option ist ein verschlüsselter Tresor mit eigener PIN und einzeln sperrbaren Alben.

Apple Fotos: integrierte Sperre

Das Album „Ausgeblendet“ ist auf unterstützten iOS-Versionen standardmäßig geschützt. Zum Öffnen nutzt du Face ID, Touch ID oder deinen Gerätecode. Eine beliebige eigene PIN ausschließlich für dieses Apple-Album lässt sich damit nicht festlegen. Apple beschreibt die aktuelle Bedienung hier.

Eine separate PIN für private Inhalte

Hide Photos verwendet eine sechsstellige App-PIN und kann Face ID zum bequemen Entsperren einbeziehen. Der Tresor liegt in einem eigenen, lokal verschlüsselten Speicherbereich statt nur in der normalen Fotos-Mediathek. Das eignet sich für Nutzer, die nicht denselben Entsperrweg wie beim Systemalbum verwenden wollen.

Prüfe die Einstellungen für automatische Sperre und die geschützte App-Vorschau beim App-Wechsel. Eine PIN ersetzt nicht den Geräteschutz und schützt nicht vor jedem Angriff.

Einzelne Alben zusätzlich sperren

Neuere Versionen von Hide Photos unterstützen eigene Sperren für ausgewählte Alben. Damit kannst du beispielsweise Dokumente anders verwalten als Alltagsfotos. Eine getrennte Albensperre erhöht die organisatorische Zugriffstrennung, während sichere Sicherungen weiterhin wichtig bleiben.

Häufige Fragen

Kann ich ein einzelnes Foto in Apple Fotos mit einem eigenen Passwort sperren?

Nicht über eine frei wählbare separate PIN für jedes Foto im integrierten Album. Für getrennte Zugriffsbereiche ist eine darauf ausgelegte App eine Alternative.

Ist Face ID oder PIN besser?

Face ID ist komfortabel; eine eigenständige PIN schafft einen anderen Zugang. Entscheidend sind Gerät, Bedrohungsmodell und eine verlässliche Sicherung.

Sind alle Album-Sperren kostenlos?

Welche Funktionen enthalten sind, hängt von Version und Tarif ab. Prüfe die Angaben direkt im App Store und in der App.
