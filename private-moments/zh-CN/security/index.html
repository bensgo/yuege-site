安全机制与加密架构

了解本机 AES-GCM 加密、密钥保护、iOS 文件保护、加密备份和有限分析数据之间的区别。

认证加密而非简单隐藏

保险箱使用 AES-GCM 保护照片、视频、缩略图、Moment 文字和相关元数据。大型媒体分块处理，降低一次性明文缓冲需求。

PIN 与密钥派生

PIN 不以明文存储。Argon2id 派生密钥加密密钥（KEK），用来保护随机生成的 256 位保险箱主密钥。Face ID 仅用于设备上的便捷解锁。

iOS 的额外保护

加密文件存放在应用 Application Support 私有目录，使用 Complete File Protection。切到后台时遮挡敏感预览，必要时清理临时解密数据。

私密相机与元数据

私密相机拍摄的内容直接进入保险箱。缩略图、标题、备注和元数据同样属于敏感信息，不应视为公开资料。

独立加密备份

用户自行选择 Files、iCloud Drive、外部存储等保存加密备份的位置。备份使用独立随机盐和受 PIN 保护的密钥封装；恢复需要文件和正确 PIN，而不是旧设备的 Face ID。

分析范围与限制

Firebase Analytics 仅进行有限的应用使用和质量度量，不记录导入动作、媒体数量或保险箱内容；不启用 IDFA、AdSupport、IDFV 收集、Google Signals 或广告功能。任何软件都不能保证绝对安全。
