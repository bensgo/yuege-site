Windows / Mac Wi-Fi 传输（Pro）

  1. 在 iPhone 解锁 Hide Photos，选择允许共享的相册和文件夹。
  2. 启动 Wi-Fi Transfer，复制手机显示的局域网访问地址，保持 App 打开。
  3. 在同一可互通局域网的 Windows 或 Mac 浏览器中打开地址。
  4. 在 iPhone 确认电脑请求并允许连接，上传或下载文件，完成后停止服务。

Wi-Fi Transfer / iCloud Sync / Backup

Wi-Fi Transfer 用于 iPhone 与电脑间主动、临时的局域网传输；iCloud 加密同步（Pro）用于受支持的 Apple 设备间同步，而加密备份用于创建独立恢复文件。

Windows / Mac Wi-Fi 传输（Pro）

当前 Wi-Fi Transfer 使用 HTTP，照片、视频、文件及连接数据在传输途中不受加密保护。请仅在可信私人 Wi-Fi 网络使用，只允许认识的电脑连接，并在结束后停止传输。

FAQ

Windows 电脑可以使用吗？

可以。使用 Windows Chrome 或 Edge 浏览器访问。

Wi-Fi 传输加密吗？

不加密。当前 HTTP 传输不提供传输层加密。

免费版可以使用吗？

Wi-Fi Transfer 是 Pro 功能，App 本身可免费下载。
