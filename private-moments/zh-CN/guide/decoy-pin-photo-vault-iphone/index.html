什么是伪装保险箱 PIN？

Hide Photos 的较新版本最多支持三个伪装保险箱，各有自己的 PIN、内容与密钥，管理功能在主保险箱内操作。

伪装保险箱不是抗胁迫保证。启用后 Face ID 解锁和 Face ID 恢复可能不可用；备份仅包含当前打开的保险箱。

推荐的操作步骤

PIN 与密钥派生

PIN 不以明文存储。Argon2id 派生密钥加密密钥（KEK），用来保护随机生成的 256 位保险箱主密钥。Face ID 仅用于设备上的便捷解锁。

iOS 的额外保护

加密文件存放在应用 Application Support 私有目录，使用 Complete File Protection。切到后台时遮挡敏感预览，必要时清理临时解密数据。

独立加密备份

用户自行选择 Files、iCloud Drive、外部存储等保存加密备份的位置。备份使用独立随机盐和受 PIN 保护的密钥封装；恢复需要文件和正确 PIN，而不是旧设备的 Face ID。

帮助中心

忘记 PIN 可以让开发者恢复吗？

不能。开发者没有服务器端的保险箱密码恢复副本，也无法远程解锁或解密您的数据。请使用已配置且当前版本支持的恢复方式。

为什么恢复加密备份需要 PIN？

备份需要正确 PIN 才能解密，只有备份文件不够。请安全保存 PIN 并测试恢复。

换新 iPhone 怎样恢复？

在旧设备创建加密备份并保存文件；在新设备用正确 PIN 恢复。Face ID 是设备本地能力，恢复后需重新启用。
